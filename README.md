# MaaSH

「时空中的绘旅人」日常小助手，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework)，图形界面使用 [MFAAvalonia](https://github.com/SweetSmellFox/MFAAvalonia)。

> 测试版：任务都已在作者的模拟器上跑过，但游戏常有活动弹窗、版本更新，仍可能遇到识别不到的画面，欢迎用 Issue 反馈（附上 `debug/on_error/` 里的截图）。

只截图 + 模拟点击，不修改游戏、不读写内存、不走任何接口。绝不点击人民币（¥）或钻石标价的购买按钮。

## 下载和使用

1. 在 [Releases](https://github.com/LiliiPop/MaaSH/releases) 下载 `MaaSH-win-x86_64-版本号.zip`，解压到任意文件夹（例如 `D:\MaaSH`）。
2. 第一次运行先双击 `DependencySetup_依赖库安装_win.bat` 安装运行库（只需一次）。
3. 打开 MuMu 模拟器，再双击 `MaaSH.exe`（旧版本留下的 `MFAAvalonia.exe` 是同一个程序，可以不用管）。
4. 在「连接」里选择模拟器（见下一节），按游戏安装渠道选择资源「官服」或「B服」。
5. 勾选想跑的任务，然后开始运行。任务会按列表顺序执行，「每日任务领取」「周常领取」请放在其他日常之后。

界面主题（浅色 / 深色、配色）和背景图片可以在 MFAAvalonia 的设置里自己改。

### 第一次使用前：设置 MuMu

- MuMu「设置中心 → 显示」分辨率选 **平板版 1280×720**（16:9），保存后重启模拟器。
- 在模拟器里**先手动登录一次游戏**；MaaSH 用已登录的账号进游戏，不保存、不输入账号密码。
- 跑脚本时模拟器窗口不要最小化；多账号请每个账号用一个单独的 MuMu 实例。
- 实时画面黑屏时，到「设置 → 连接设置」把截图方式换成「默认」。

### 预设

任务列表上方可以一键套用预设：

| 预设 | 内容 | 建议频率 |
| --- | --- | --- |
| 每日日常 | 启动 → 全部日常 → 领每日 / 周常奖励 → 关闭游戏 | 每天一次（05:00 刷新后） |
| 领体力（定时用） | 启动 → 领体力 → 关闭游戏 | 每天 12:05、17:35 各一次 |
| 每周任务 | 启动 → 时光电影院 → 月卡每周购买 → 绘卷回忆扫荡 → 关闭游戏 | 每周一次 |

### 定时领体力

主界面「今日体力」只在午间（12:00–15:00）和晚间（17:30–21:00）能领，最省心的是交给 MaaSH 自带的定时：

1. 在 MaaSH 里**新建一个配置**（例如叫「领体力」）。
2. 在这个配置的任务列表里只勾选 **✈️启动游戏、🍓领体力、🏁结束后操作**（结束后操作选「关闭游戏」），其他都不勾。
3. 在设置里的「定时」添加两条每天执行的定时：**12:05** 和 **17:35**，都选择「领体力」这个配置。
4. 想顺便把日常也定时跑，可以再加一条 05:30 左右的定时，选择跑日常的那个配置。
5. 定时只在 MaaSH 窗口开着时才会触发（可以最小化），电脑和模拟器也要开着。

两条定时不要设得太近，同一时间只能跑一个配置。

## 连接模拟器

MaaSH 打开后会自动查找正在运行的模拟器，在「连接」里选择你的模拟器即可。

如果没有自动找到，或者你开了多个模拟器，需要手动填写 ADB 地址：

1. 打开桌面上的「MuMu 多开器 12」。
2. 找到右上角或设置里的「ADB 端口」，展开后能看到每个模拟器一行，例如：

   ```text
   #0   上班模拟器   5555,16385
   ```

3. 取你运行游戏的那一行最后的数字（上例是 `16385`），在 MaaSH 的连接设置里填写 `127.0.0.1:16385`。

不同电脑、不同多开实例的端口可能不一样，请以你自己多开器里显示的为准。

## 任务列表

添加任务时按分组显示：🚀启动 / ☀️每日 / 🧩每日单项（已含在打包里，默认折叠）/ 📅每周 / 🎁领奖励 / 🏁结束。新建配置时选「每日日常」预设就是推荐顺序；每个任务的说明文字在 `tasks/doc/*.md`，可以直接改。

| 任务 | 说明 | 状态 |
| --- | --- | --- |
| 🏫校园打包 | 进一次校园连做 🍀收礼 + 🎁赠礼 → 🗓️日程 → 🖼️画展；结果不明时才去任务页补做 | 可用 |
| 🎨画灵绘卷打包 | 从任务页连做 🌟画灵提升 → 📜绘卷提升 | 可用（待实测） |
| ✈️启动游戏 | 启动游戏、点击登录、关闭公告，停在主界面 | 可用 |
| 📅签到 | 任务页「签到」自动签到并领奖励 | 可用 |
| ✉️领邮件 | 全部领取并已读，不删除邮件 | 可用 |
| 💰月卡领取 | 采购 → 月卡 → 领取今日礼包 | 可用 |
| 💌好友体力 | 一键赠送并领取好友体力 | 可用 |
| 🗓️安排日程 | 第一页随机；第二页可沿用随机或指定五位男主，找信封并处理对话；校园打包共用此选项 | 指定模式待实测 |
| 🎁出行赠礼 | 换成选定角色，直接送礼物列表第一个；「送礼次数」可设送几个（默认 1） | 可用 |
| 🍀出行收礼 | 可先换成选定角色（默认不换），反复点人物直到弹出奖励 | 可用 |
| 🖼️画展宣传 | 先领已结束场次，再按 NPC 提示的地点开新画展 | 可用 |
| 🎀免费礼包 | 常驻礼包「每日惊喜盒子」，只点「免费」；可选「活动免费礼包」（默认关闭）：通过红点机制打开带红点的页签，领价格写着「免费」的礼包（第一次运行可能把带红点的页签都看一遍） | 可用 |
| 🏖️假日一键领取 | 先领假日清单，再领假日计划（可分别开关） | 可用 |

| 🍓领体力 | 午间、晚间各检查一次，按钮是「领取」才点；体力领完、主界面入口消失时直接算完成（适合定时单独运行） | 可用 |
| 🌟画灵提升 | 任务页「升级任意画灵1次」：从图鉴第一张往右找等级未满的，升 1 级（建议收藏一张未满级的画灵） | 可用 |
| 📜绘卷提升 | 任务页「升级任意绘卷1次」：同上，升 1 级绘卷 | 可用 |
| 🎭手偶剧场三合一 | 保留观看、评论、点赞；完成后可领取观影券进度奖励（可关闭） | 领券收尾待实测 |
| 👍手偶剧场点赞 | 只做任务页「手偶剧场点赞1次」：前往 → 播完点赞（今天已赞就跳过，不评论） | 可用 |
| 🍰清体力 | 练习 → 星间剧场 / 画材收罗 / 梦之旅途 / 作战演练，按设置刷到至少 60 或 120 体力，再回任务页确认「累计消耗60点体力」。可选难度、道具符（快速过关）或实际战斗（自动选第一个助战）；体力不够时可跳过或清完；默认不用体力道具，绝不花钻石买体力 | 可用（待实测） |

| 📆周常领取 | 任务页「周常」一键领取到按钮变灰。只领已完成的奖励，不会做周常任务（周常靠一周累计） | 可用 |
| 🏁结束后操作 | 可选：关闭游戏 / 返回主界面 / 不动 | 可用 |
| 💤关闭绘旅人 | 关闭游戏 | 可用 |
| 🧪冒烟测试 | 开发用：确认能连上模拟器、能启动游戏 | 可用 |

## 注意事项

- 本项目是玩家自制的开源工具，与网易及「时空中的绘旅人」官方无关。游戏内的文字、图片版权归原权利人所有；`resource/image` 里只有用于识别的界面小截图。
- 使用自动化工具可能违反游戏用户协议，请自行承担风险。
- 仅供个人学习和自用，禁止用于商业用途或代练。
- 默认不会花钱或钻石：标着 ¥ 或钻石价签的弹窗一律取消。例外只有你手动开启的「🛒月卡每周购买」（1200 钻石）和清体力的「自动使用体力道具」（有误用钻石的风险）。
