# MaaSH

「时空中的绘旅人」日常小助手，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework)，图形界面使用 [MFAAvalonia](https://github.com/SweetSmellFox/MFAAvalonia)。

> 测试版：任务都已在作者的模拟器上跑过，但游戏常有活动弹窗、版本更新，仍可能遇到识别不到的画面，欢迎用 Issue 反馈（附上 `debug/on_error/` 里的截图）。

只截图 + 模拟点击，不修改游戏、不读写内存、不走任何接口。绝不点击人民币（¥）或钻石标价的购买按钮。

## 下载和使用

1. 在 [Releases](https://github.com/LiliiPop/MaaSH/releases) 下载 `MaaSH-win-x86_64-版本号.zip`，解压到任意文件夹（例如 `D:\MaaSH`）。
2. 第一次运行先双击 `DependencySetup_依赖库安装_win.bat` 安装运行库（只需一次）。
3. 打开 MuMu 模拟器，再双击 `MFAAvalonia.exe`。
4. 在「连接」里选择模拟器（见下一节），资源选「官服」。
5. 勾选想跑的任务，然后开始运行。任务会按列表顺序执行，「每日任务领取」「周常领取」请放在其他日常之后。

界面主题（浅色 / 深色、配色）和背景图片可以在 MFAAvalonia 的设置里自己改。

### 预设

任务列表上方可以一键套用预设：

| 预设 | 内容 | 建议频率 |
| --- | --- | --- |
| 每日日常 | 启动 → 全部日常 → 领每日 / 周常奖励 → 关闭游戏 | 每天一次（05:00 刷新后） |
| 领体力（定时用） | 启动 → 领体力 → 关闭游戏 | 每天 12:05、17:35 各一次 |
| 每周电影院 | 启动 → 时光电影院 → 关闭游戏 | 每周一次 |

### 定时领体力

主界面「今日体力」只在午间（12:00–15:00）和晚间（17:30–21:00）能领，最省心的是交给 MaaSH 自带的定时：

1. 新建一个配置（例如叫「领体力」），套用预设「领体力（定时用）」。
2. 在设置里的「定时」添加两条每天执行的定时：**12:05** 和 **17:35**，都选择「领体力」这个配置。
3. 想顺便把日常也定时跑，可以再加一条 05:30 左右的定时，选择套用了「每日日常」的配置。
4. 定时只在 MaaSH 窗口开着时才会触发（可以最小化），电脑和模拟器也要开着。

两条定时不要设得太近，同一时间只能跑一个配置。

## 连接模拟器

MaaSH 打开后会自动查找正在运行的模拟器，在「连接」里选择你的模拟器即可。

如果没有自动找到，或者你开了多个模拟器，需要手动填写 ADB 地址：

1. 打开桌面上的「MuMu 多开器 12」。
2. 找到右上角或设置里的「ADB 端口」，展开后能看到每个模拟器一行，例如：

   ```text
   #0   上班模拟器   5555,16385
   ```

3. 取你运行游戏的那一行最后的数字（上例是 `16385`），在 MaaSH 的连接设置里填写 `127.0.0.1:16385`。

不同电脑、不同多开实例的端口可能不一样，请以你自己多开器里显示的为准。
