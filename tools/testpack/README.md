# MaaSH 测试包

不打开 MaaSH 界面，按「套件」文件自动：切换账号 → 逐个跑任务 → 记录每步耗时、进了几次任务页、按了几次返回键、有没有失败/重开 → 生成报告。

## 第一次使用
1. 双击 `安装测试环境.bat`：在本文件夹里装一个独立的 Python 和 MaaFramework（只装一次，大约 100 MB）。
2. 用记事本打开 `accounts.json`，把「账号1」「账号2」改成网易登录框**历史账号列表**里显示的文字（邮箱 @ 前面那段即可）。要切的号必须在这个模拟器上手动登录过。这个文件只在你电脑上，不会上传。

## 每次跑
1. **关掉 MaaSH**，模拟器保持开着。
2. 双击 `跑测试包.bat`（默认跑 `suites\标准.json`），或把别的套件文件拖到它上面。
3. 跑完看 `F:\MaaSH\testreports\<时间_套件名>\报告.md`。有问题把整个文件夹发给 Claude。

## 自带的套件
| 套件 | 内容 |
|---|---|
| `标准.json` | ① 账号1 逐个跑单项 → ② 账号2 跑打包组合 → ③ 切回账号1 重跑单项（今天做过了，应该很快跳过）→ ④ 关游戏 |
| `快速.json` | 不切账号，当前登录的号跑一遍推荐的每日组合 |
| `每周.json` | 当前账号跑绘卷回忆扫荡、时光电影院、周常领取 |

## 自己写套件
复制一份 `suites\标准.json` 改。每一步可以只写任务名，也可以写成：
```json
{"task": "🏫校园合一", "option": {"画展宣传时间": "2小时"}, "最长秒数": 300, "必须经过": ["Flag_画展完成"], "不能经过": ["公共_任务失败"]}
```
- 任务名、选项名、可选值：运行 `python\python.exe run_suite.py --list` 查看。
- `"account": "账号1"` 写在轮次上：这一轮开头会先用「✈️启动绘旅人 + 使用指定账号登录」切到这个号。
- `"共用设置"`：📸质检截图勾哪些环节（截图存在报告文件夹的 debug\screencap）。
- `"最长秒数"`：超过就在报告里标出来（不会中断）。
- 检查写得对不对：`检查套件.bat`（不连模拟器）。
