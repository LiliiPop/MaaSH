从**主界面**进社交 → 作品 → 热门剧场第一部观看。三个开关（默认都开）：

- **剧场点赞**：看完点赞（原来就是红心会先取消再点），返回社交看到「点赞一次他人的视频」打勾就结束。关掉则看完直接返回。
- **剧场评论**：播放时点画面 → 点底部输入框 → 点上方输入栏 → 输入「评论内容」→ 回车 → 点纸飞机发送。没做手机验证的号游戏不让评论，会重开游戏并跳过本任务。评论内容建议只用数字或英文（模拟器里输入中文可能失败）。
- **领取观影券进度奖励**：最后在社交页领观影券进度奖励（观看 / 点赞 / 评论都算进度）。已领过或没有奖励时直接返回。

观看本身总会做。播放要等 1–3 分钟；写评论的每一步之间会停 1 秒左右等游戏反应，中途看起来像卡住是正常的。

原来的「👍手偶剧场点赞」已并进来：只想点赞就把「剧场评论」关掉。
