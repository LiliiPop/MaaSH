三合一：观看 + 点赞 + 评论。从**主界面**进社交 → 作品 → 热门剧场第一部：播放时点画面 → 点底部输入框 → 点上方输入栏 → 输入「评论内容」→ 点纸飞机发送；看完后点赞（原来就是红心会先取消再点），返回社交看到「点赞一次他人的视频」打勾就结束。

今天已经点过赞也会照常观看和评论。播放要等 1–3 分钟；写评论的每一步之间会停 1 秒左右等游戏反应（点输入框、输入、按回车、点纸飞机），中途看起来像卡住是正常的。

评论内容建议只用数字或英文（模拟器里输入中文可能失败）。
