# 任务说明文件

每个任务在 MaaSH 里显示的说明就是下面对应的 .md 文件，直接改文字即可（支持 Markdown：`**加粗**`、空一行分段、`- 列表`）。
仓库里的位置是 `assets/tasks/doc/`，安装后在 MaaSH 目录的 `tasks\doc\`。改完重启 MaaSH 生效。
只在安装目录里改的话，下次更新会被新版覆盖，所以正式修改请改仓库里的文件。
