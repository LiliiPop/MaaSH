启动游戏，进入默认账号，关掉公告，停在主界面。

- 可设置等待上限；认不出的开屏会在画面静止后点底部进入。
- 资源可选「官服」或「B服」（B服仍在测试中）。首次登录、验证码请手动处理。
- 「使用指定账号登录」（官服）和「B服登录记录核对」（B服）只从模拟器里已保存的登录记录中选账号，不会输入密码。

**第一次使用**：MuMu 分辨率设成 1280×720（设置中心 → 显示 → 平板版），先在模拟器里手动登录一次游戏；完整的 MuMu 和 MaaSH 设置步骤见公告（设置 → 关于 → 显示公告）。

为了保证脚本的成功率，各任务里有一些冗余的等待与动作，看起来稍慢是正常的。遇到 bug 请到 [GitHub](https://github.com/LiliiPop/maash/issues) 提 issue，最好附上 MaaSH 目录下 `debug` 文件夹里的截图和日志。
