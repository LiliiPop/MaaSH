启动游戏，点击登录界面进入默认账号，关闭所有公告，停在主界面。

可设置等待上限；认不出的开屏会在画面静止后点底部进入。

资源可选择「官服」或「B服」。B 服包名为 `com.netease.skzdhlr.bilibili`，启动、关闭和异常重开都使用该包名；首次登录或验证码请手动处理。

B 服专用选项「B服登录记录核对」默认关闭。开启后填写已保存账号的昵称片段，只在已出现的 B 服登录记录面板中选择并核对，不主动注销当前游戏账号；核对不符则停止。官服原来的网易历史账号切换选项仍只对官服生效。

**第一次使用**：MuMu 分辨率设成 1280×720（设置中心 → 显示 → 平板版），先在模拟器里手动登录一次游戏；完整的 MuMu 和 MaaSH 设置步骤见公告（设置 → 关于 → 显示公告）。
