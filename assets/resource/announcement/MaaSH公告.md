# MaaSH 公告

## 第一次使用：设置 MuMu 和 MaaSH

**MuMu 模拟器（推荐 MuMu 模拟器 12）**

1. 打开 MuMu 的「设置中心 → 显示」，分辨率选 **平板版 1280×720**（或其他 16:9 分辨率，1280×720 最稳），保存后重启模拟器。
2. 在模拟器里装好「时空中的绘旅人」（目前只支持官服），**先手动登录一次**，MaaSH 之后会用这个已登录的账号进游戏。MaaSH 不保存、也不会输入账号密码。
3. 游戏里不用改设置：全景主题和默认主题都支持。跑脚本时**模拟器窗口不要最小化**（可以被别的窗口挡住）。
4. 多开时，每个账号用一个单独的 MuMu 实例，各自在里面登录一次。

**MaaSH**

1. 解压后，第一次先双击 `DependencySetup_依赖库安装_win.bat` 安装运行库（只需一次）。
2. 先打开 MuMu，再打开 `MaaSH.exe`。
3. 在「连接」里选你的模拟器，资源选「官服」。没有自动找到、或者开了多个模拟器时，打开「MuMu 多开器 12」查看 ADB 端口，例如 `#0 上班模拟器 5555,16385`，就在连接设置里填 `127.0.0.1:16385`。
4. 实时画面黑屏：到「设置 → 连接设置」把截图方式从「EmulatorExtras」换成「默认」。
5. 在任务列表上方套用预设「每日日常」，或者自己勾选任务；「每日任务领取」「周常领取」放在其他日常之后。
6. 想定时跑：在「设置 → 定时」里添加，只在 MaaSH 窗口开着时触发（可以最小化）。

这份说明可以随时在「设置 → 关于 → 显示公告」里再打开。

## 使用前请看

- MaaSH 是非官方工具，只截图 + 模拟点击，不注入、不读写内存、不改游戏文件。使用有风险，请自行判断。
- 默认**不会花钱、不会花钻石**：标着 ¥ 或钻石价签的弹窗一律点空白取消。
- 例外只有两个，都默认关闭，需要你自己打开：
  - 「🛒月卡每周购买」：会花 **1200 钻石**买「超值颜料礼盒」。
  - 「🍰清体力」的「自动使用体力道具」：体力不够时用体力道具补充。已做防呆（只剩钻石时一律取消），但无法保证 100% 不误用钻石，开启视为已知风险。

## 最近更新

- 免费礼包新增「活动免费礼包」（默认关闭，需要的话在任务设置里打开）：通过红点机制找活动页签里的免费礼包；领到自选物品时弹出的挑选窗口会自动关掉，物品请自己去背包里选。
- 新增「🍰清体力」（测试中）：在任务设置里选关卡、难度、道具符、60/120 体力档；默认不勾选。
- 新增「📼绘卷回忆扫荡」：每周一次，不花体力，已加进「每周任务」预设。
- 新增「🛒月卡每周购买」：每周一次，已加进「每周任务」预设。
- 领体力：只认「今日体力」图标下方的文字再点图标，不会再误点旁边的「生日返礼」「限时购」；体力领完、图标消失时直接算完成。
- 新增「稍后再说」弹窗处理（如角色生日回礼），各任务开始前都会先关掉，**绝不点「回礼 ¥1」**。
- 出行收礼可以选择角色（任务设置里的「收礼角色」，默认不换人）。

## 小贴士

- 实时画面黑屏：模拟器不要最小化；仍然黑屏的话，到「设置 → 连接设置」把截图方式从「EmulatorExtras」换成「默认」。
- 领体力建议用定时：新建一个配置，只勾「启动绘旅人」「领体力」「结束后操作」，再在「设置 → 定时」里给它加 12:05、17:35 两条。
